# セキュリティ方針

Glassbox AIは外部通信、ユーザーアカウント、クラウド保存を持たないローカル静的Webアプリです。それでも、JSON読み込み、ファイル出力、DOM表示などの境界は安全性レビューの対象です。

## 対応対象

最新版の既定ブランチを対象とします。古いローカルコピーや改変版は個別サポート対象外です。

## 脆弱性の報告

公開リポジトリ化した時点で、GitHubのPrivate vulnerability reportingを有効にし、非公開のSecurity Advisoryを正式な報告窓口とします。公開前の現在は外部報告窓口が未設定です。公開Issueへ、悪用可能な再現手順や未修正の脆弱性詳細を投稿しないでください。

報告には、影響する版、再現条件、期待結果と実際の結果、考えられる影響を含めてください。修正前の公開時期や応答期限は一律には保証せず、再現確認後に影響範囲と対応方針を共有します。

## 信頼境界

- インポートするネットワークJSONとRL履歴JSONは信頼しない入力として検証します。
- JSON内の文字列をHTMLとして実行せず、テキストとして表示します。
- 外部CDN、外部API、遠隔測定は使用しません。
- ローカルHTTPサーバーは教材ファイルの配信だけに使用し、インターネット公開を前提にしません。
