# Glassbox AIへの貢献

Glassbox AIは、結果だけでなく「その数値がどこから来たか」を追えることを最優先にする教育用実験装置です。機能追加や修正では、表示上の説明と実際の計算を同じデータ源へ接続してください。

## 開発環境

- Node.js 20以降（自動テスト用）
- Python 3（ローカルHTTPサーバー用）
- 外部パッケージのインストールは不要

```powershell
cd glassbox-ai
npm run check
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。`file://` 直開きはES Modulesの制約があるため対象外です。

## 変更の原則

1. ニューラルネットワーク、順伝播、逆伝播、方策勾配は自前実装を維持します。
2. 外部AI API、学習済みモデル、機械学習ライブラリを追加しません。
3. UIはモデルが生成した実値または完全スナップショットだけを表示します。説明用のダミー値を混ぜません。
4. 既存の139ステップ数学タイムラインと、環境経験を扱う強化学習の因果軸を混在させません。
5. 数学処理を変更する場合は、手計算または有限差分で根拠を検証するテストを追加します。
6. 観測事実と、人間による意味解釈を区別します。

## テスト

```powershell
npm test
npm run test:coverage
npm run check
```

ブラウザ変更では、少なくとも次を手動確認してください。

- Consoleにerrorがない
- 139ステップ推論・教師あり学習を開始できる
- RLの新規エピソード、前後移動、一括実行が整合する
- 環境履歴の前状態、行動、後状態、報酬、累積報酬が実遷移と一致する
- 狭い画面でも主要操作へ到達でき、横長表は表領域内だけでスクロールする
